# Brand Book Oficial — BELENTANI // JUDAS ERA

## 1. Manifiesto de Identidad Corporativa

BELENTANI // JUDAS ERA es una plataforma digital de alta vanguardia que fusiona la dirección de arte cinemática, la mitología contemporánea y la computación cuántica. La identidad visual rechaza rotundamente el uso indiscriminado de colores estridentes (efecto "arcoíris") o múltiples familias tipográficas inconexas. Se adopta una estética de **Lujo Oscuro / Aetherpunk Editorial**, donde la precisión geométrica se encuentra con la sobriedad monástica.

## 2. Sistema Tipográfico Oficial

Para garantizar la legibilidad editorial y la cohesión de marca, se restringe el ecosistema tipográfico a exactamente dos familias complementarias:

1. **Tipografía Primaria de Titulares (Display & Editorial):** *Cinzel Decorative* (o *Cinzel* para subtítulos formales). Aporta solemnidad, elegancia clásica y carácter monumental.
2. **Tipografía Secundaria y de Interfaz (UI & Mono):** *Chakra Petch* para textos limpios y futuristas, combinada con *JetBrains Mono* para metadatos, consola y coordenadas técnicas.
3. *Se prohíbe terminantemente el uso de fuentes genéricas como Inter o mezclas arbitrarias en una misma pantalla.*

## 3. Paleta Cromática Restringida (The Obsidian Monolith)

La paleta cromática se basa en tonos profundos con un único punto de acento magnético:

- **Void Black (#030303):** Fondo absoluto y base espacial para transmitir inmensidad.
- **Obsidian Glass (#0a0a0c):** Superficies modulares con bordes biselados.
- **Blood Red (#ff003c):** Único color de acento activo para llamadas a la acción, estados críticos y elementos focales clave.
- **Sacred Gold (#ffd700):** Tono secundario reservado exclusivamente para la revelación final (La Llave Dorada).
- **Stellar White (#ffffff):** Texto principal de alta claridad y contraste (cumplimiento WCAG AAA).

## 4. Normas de Composición y UI

- **Retícula Asimétrica y Editorial:** Espacios generosos, tipografía monumental y ausencia de cajas flotantes recargadas.
- **Bordes Biselados y Contraste:** Uso de `clip-path` geométrico sutil en lugar de radios de curvatura excesivos o genéricos.
- **Motion Intencional:** Las animaciones duran entre 200ms y 400ms con curvas `cubic-bezier` personalizadas; los shaders de fondo son sutiles y atmosféricos, nunca invasivos.
